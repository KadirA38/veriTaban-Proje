Otel Rezervasyon Sistemi - Veritabanı Projesi

Bu proje, Veritabanı Yönetim Sistemleri dersi için hazırlanmış bir otel rezervasyon ve konaklama yönetim sistemidir. Python (Flask) ve MySQL kullanılarak katmanlı mimariye uygun şekilde geliştirilmiştir.

Kullanılan Teknolojiler

Python & Flask

MySQL

Flask-SQLAlchemy (ORM)

JWT (Kimlik Doğrulama)
